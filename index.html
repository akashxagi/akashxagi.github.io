01

AI Sales Assistant SaaS — Automotive

Multi-tenant, production-grade conversational AI for automotive dealerships with semantic inventory search, real-time scheduling, and damage analysis.

35% Retrieval relevance lift (MRR@5)
22% → 8% Hallucination rate in production
~90% Manual dealer workflow steps eliminated
14 Function-calling tools in the ReAct sales agent

Problem

Automotive dealerships needed a 24/7 AI sales assistant that could understand vague natural language queries ("sporty dark SUV for family use"), search real-time inventory semantically, handle trade-in requests with AI damage analysis, book test drives via Google Calendar, and deploy as a single <script> tag on any dealer website — all as a multi-tenant SaaS.

Approach

Built a phase-aware conversational AI (6 phases: greeting → acquisition → discovery → recommendation → appointment → contact capture) with 14 function-calling tools. The RAG pipeline transforms each vehicle's 25+ attributes into lifestyle-annotated semantic descriptions using custom color, body-style, and feature mapping dictionaries before generating OpenAI embeddings stored in pgvector. At query time, cosine similarity retrieves top candidates, then structured filters apply bonus scoring. Deployed on AWS EC2 with Nginx + Gunicorn + 4 Uvicorn workers; nightly inventory sync via Cox Automotive SFTP → CSV parsing → PostgreSQL upsert → RAG re-indexing → MongoDB sync.

Key Decisions

SSE over WebSocket for AI streaming (CDN/proxy compatibility, auto-reconnect). Redis-backed sessions with dual persistence to PostgreSQL for FK relationships, enabling multi-worker horizontal scaling. SHA-256 hashed API keys with prefix-based identification and scoped RBAC (widget/admin/full hierarchy). Fire-and-forget asyncio.create_task() for lead sending and notifications to avoid blocking main requests. Chroot-jailed SFTP user for Cox Automotive inventory feeds at zero additional infrastructure cost.

Tech Stack

FastAPI PostgreSQL + pgvector Redis OpenAI GPT-4o OpenAI Embeddings AWS EC2 / RDS / S3 Nginx + Supervisor SQLAlchemy ORM MongoDB Atlas Google Calendar API SSE Streaming Vanilla JS (9.7K LOC) APScheduler Pandas
02

Enterprise AI/ML Platform

No-code, full-lifecycle AI platform unifying RAG-powered document Q&A, automated ML pipeline orchestration, NL2SQL, and private offline inference.

40% ML workflow turnaround reduction
80% GPU utilization on local vLLM inference
7-step Automated ML pipeline (zero code)
Zero egress Private on-premise inference — data never leaves the machine

Problem

Organizations face a fragmented toolchain: separate systems for document Q&A, exploratory data analysis, ML training, and deployment. Data scientists spend 60–80% of their time on preprocessing. Non-technical stakeholders can't explore data without writing code, and organizations with strict data privacy requirements can't send proprietary data to cloud inference APIs.

Approach

Two production subsystems: (1) A RAG-powered Document Q&A chatbot with hybrid retrieval (70% vector similarity + 30% keyword overlap via Jaccard), session-isolated FAISS stores per user backed by BAAI/bge-m3 multilingual embeddings, and query enhancement via Gemini. (2) A full-lifecycle ML Pipeline Platform with a 7-step automated orchestrator (data cleaning → EDA → feature engineering → training → Optuna Bayesian HPO → SHAP evaluation → model serialization), conversational NL2SQL powered by DuckDB with self-correcting retry loop, a visual N8N-style preprocessing canvas, and private Docker-bundle export enabling on-premise inference via vLLM with 4-bit GPTQ quantization.

Key Decisions

Custom FrequencyEncoder and TargetEncoder sklearn transformers — produce exactly 1 output column regardless of cardinality, solving memory explosion from high-cardinality one-hot encoding. Cooperative cancellation pattern (flag-based checkpoints) instead of unsafe thread termination. Content-hash deduplication (SHA-256) for zero-copy cross-session dataset sharing. Multi-stage Docker builds reducing code-change rebuild from ~10min to ~30sec. Docker bundle exporter auto-includes platform pickle dependencies so custom transformers deserialize correctly in air-gapped environments.

Tech Stack

FastAPI LangChain Google Gemini vLLM + GPTQ FAISS BAAI/bge-m3 DuckDB scikit-learn XGBoost Optuna SHAP Vue 3 + Pinia ECharts Docker Parquet + Snappy MLflow
03

Interview Intelligence Platform

Autonomous meeting bot with AI-powered cognitive bias detection, speaker-diarized transcription, and structured PDF reporting — zero manual intervention.

2hr → 40s Post-interview analysis time
20 Cognitive bias types detected
16 Keyword extraction categories
100% Autonomous — zero human steps required

Problem

Hiring processes suffer from unconscious interviewer bias and lack structured documentation. Recruiters manually take notes, miss key discussion points, and have no objective measure of interview fairness. There's no scalable way to analyze interview quality and bias patterns across hundreds of sessions without enormous manual overhead.

Approach

End-to-end autonomous pipeline: a headless Chrome Selenium bot joins scheduled Digital Samba video calls via multi-selector element discovery (4 CSS + 5 XPath fallbacks for robustness against dynamic UI), monitors participant presence, triggers recording, and hands off to the analysis pipeline on meeting end. AssemblyAI handles speech-to-text with speaker diarization (async polling loop, 20 retries at 30s intervals). GPT-4o-mini detects 14 interviewer + 6 interviewee + 8 cross-cutting bias categories, outputting structured JSON with magnitude (0–10) and chain-of-thought reasoning at temperature 0.3. GPT-4 extracts 16 recruitment keyword categories with chunked processing (4,000-char windows) and cross-chunk deduplication. ReportLab generates structured A4 PDFs auto-uploaded to Google Drive with email notification.

Key Decisions

Producer-consumer queue.Queue pattern to decouple video downloads from CPU-intensive AI analysis, preventing blocking during concurrent meetings. Per-meeting monitoring threads for parallel session handling. Exponential backoff (10 retries, 5s → 50s) for async recording availability from Digital Samba's processing pipeline. Subprocess isolation for video analysis — crashes in the analysis process can't take down the main bot process. Graceful degradation: always generates a PDF report even when AI analysis fails, ensuring the meeting lifecycle always reaches a terminal state.
